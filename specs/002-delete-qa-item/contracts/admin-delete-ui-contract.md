# Contract: Admin Delete UI Flow

## UI 구성
- 목록 표시: 테이블(질문/답변/작업)
- 작업 컬럼: 각 행에 `🗑️ 삭제` 버튼
- 확인 다이얼로그: `이 항목을 삭제하시겠습니까?`
- 액션: `예`, `아니오` (+ 다이얼로그 외부 클릭 취소)

## 이벤트 플로우
1. 삭제 버튼 클릭
   - 결과: 다이얼로그 표시, 대상 `qa_id` 상태 저장
2. `아니오` 또는 외부 클릭
   - 결과: 다이얼로그 닫힘, 삭제 미실행
3. `예` 클릭
   - 결과: `삭제 중...` toast 표시, 백엔드 삭제 실행
4. 성공
   - 결과: `✓ 삭제되었습니다` toast + 목록 재조회
5. 실패
   - 결과: `❌ 삭제 실패했습니다 - [원인]` toast

## 페이지 규칙
- 페이지당 10개 고정
- 현재 페이지 마지막 항목 삭제로 비어 있으면 페이지 1로 리셋
