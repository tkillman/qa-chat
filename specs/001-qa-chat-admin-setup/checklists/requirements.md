```

```

```
요구사항 FR-003: 관리자는 질문과 답변을 입력하고 "DB 업데이트" 버튼으로...
시나리오: 로그인 성공 → 관리자 화면 (Q&A 입력) → DB 업데이트
```

### 사용자 요청 #3: ChromaDB 업데이트 기능
✅ **반영됨**: 명세서 US3 (ChromaDB 업데이트)
```
요구사항 FR-003: 관리자는 질문과 답변을 입력하고 "DB 업데이트" 버튼을 클릭하여 ChromaDB를 업데이트합니다. 
요구사항 FR-001: 시스템은 앱 시작 시 init.txt에서 질문/답변을 읽어 ChromaDB에 로드해야 함
시나리오: Q&A 입력 → "DB 업데이트" 클릭 → ChromaDB + init.txt 저장 → app 재시작 시 자동 로드
```
