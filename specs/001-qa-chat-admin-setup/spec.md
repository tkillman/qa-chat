**기능 브랜치**: `001-qa-chat-admin-setup`  
**작성일**: 2026-03-03  
**상태**: 초안  
**입력**: 사용자 설명: "관리자 질문답변 입력 화면, ChromaDB 업데이트, 초기 로딩, 질문 답변 기능"

## 사용자 시나리오 및 테스트

### 사용자 스토리 1 - 초기 로딩 (우선순위: P1)

앱 실행 시 init.txt에 저장된 기존 질문과 답변 데이터를 ChromaDB에 로드합니다. 이를 통해 시작 시점부터 검색 기능을 이용할 수 있게 됩니다.

**왜 이 우선순위**: 다른 모든 기능(관리자 업데이트, 질문 답변)의 기초가 됩니다. app 시작 시 필수 기능입니다.

**독립적 테스트**: init.txt 파일이 존재할 때 앱 시작 시 ChromaDB가 해당 데이터로 초기화되는지 확인 가능합니다. init.txt가 없을 경우 빈 상태로 시작됩니다.

**수신 시나리오**:

1. **주어진** app이 처음 시작됨, **할 때** init.txt에 5개의 질문-답변이 존재, **그러면** ChromaDB가 5개 항목으로 초기화됨
2. **주어진** app이 처음 시작됨, **할 때** init.txt가 존재하지 않음, **그러면** ChromaDB가 빈 상태로 초기화됨
3. **주어진** app이 처음 시작됨, **할 때** ChromaDB 초기화 완료, **그러면** 즉시 질문 답변 기능 사용 가능

---

### 사용자 스토리 2 - 관리자 로그인 (우선순위: P1)

관리자는 패스워드(1234)를 입력하여 관리자 화면에 접근할 수 있습니다. 올바른 패스워드 입력 시 질문/답변 관리 화면으로 이동하고, 틀린 경우 오류 메시지가 표시됩니다.

**왜 이 우선순위**: 관리자 기능(질문/답변 업데이트)의 진입점입니다. P1 기능입니다.

**독립적 테스트**: Gradio UI에서 로그인 화면을 통해 패스워드 입력/검증/화면 전환을 독립적으로 테스트 가능합니다.

**수신 시나리오**:

1. **주어진** 로그인 화면이 표시됨, **할 때** 사용자가 "1234" 입력 후 확인 클릭, **그러면** 관리자 화면으로 전환
2. **주어진** 로그인 화면이 표시됨, **할 때** 사용자가 잘못된 패스워드 입력 후 확인 클릭, **그러면** "패스워드가 틀렸습니다" 메시지 표시
3. **주어진** 관리자 화면에서 로그아웃 클릭, **그러면** 로그인 화면으로 돌아감

---

### 사용자 스토리 3 - ChromaDB 업데이트 (우선순위: P2)

관리자는 질문과 답변을 입력하고 "DB 업데이트" 버튼을 클릭하여 ChromaDB를 업데이트합니다. 동시에 데이터는 init.txt 파일에 저장되어 다음 앱 시작 시에도 유지됩니다.

**왜 이 우선순위**: P1(로그인)과 독립적이지 않으나, P1 완료 후 구현 가능합니다. 관리자 데이터 관리의 핵심입니다.

**독립적 테스트**: 관리자 화면에서 질문/답변 입력 후 DB 업데이트 버튼으로 ChromaDB 및 init.txt 모두 업데이트되는지 확인 가능합니다.

**수신 시나리오**:

1. **주어진** 관리자 화면이 표시됨, **할 때** 질문 "Python이란 무엇인가?", 답변 "프로그래밍 언어입니다" 입력 후 "DB 업데이트" 클릭, **그러면** ChromaDB와 init.txt에 저장됨
2. **주어진** DB 업데이트 완료, **할 때** app 재시작, **그러면** 저장된 데이터가 자동으로 로드됨
3. **주어진** 관리자 화면에서 여러 개 질문/답변 입력, **할 때** "DB 업데이트" 클릭, **그러면** 모든 항목이 누적되어 저장됨

---

### 사용자 스토리 4 - 질문 답변 기능 (우선순위: P2)

사용자는 질문을 입력하면 ChromaDB에서 유사한 질문을 검색하여 해당하는 답변을 제공합니다. 검색 결과가 없으면 "답변을 찾을 수 없습니다" 메시지를 표시합니다.

**왜 이 우선순위**: P1(초기 로딩)이 우선되어야 하고, P2이지만 P3와는 다릅니다. 사용자-facing 핵심 기능입니다.

**독립적 테스트**: 사용자 화면에서 질문 입력 후 정확한 답변 반환, 없을 때 오류 메시지 등을 확인 가능합니다.

**수신 시나리오**:

1. **주어진** ChromaDB에 "Python이란 무엇인가?" → "프로그래밍 언어입니다" 저장됨, **할 때** 사용자가 "Python이 뭐예요?" 입력, **그러면** "프로그래밍 언어입니다" 답변 표시
2. **주어진** ChromaDB에 데이터가 없음, **할 때** 사용자가 질문 입력, **그러면** "답변을 찾을 수 없습니다" 메시지 표시
3. **주어진** ChromaDB에 여러 개 답변 존재, **할 때** 사용자 질문, **그러면** 가장 유사한 답변 1개 반환

## 엣지 케이스 및 오류 처리

- **init.txt 손상/형식 오류**: 손상된 파일은 무시하고 빈 상태로 시작, 로그 기록
- **ChromaDB 초기화 중 오류**: 사용자에게 오류 메시지 표시, Langfuse에 추적
- **중복 질문 입력**: 같은 질문이 입력될 경우 기존 항목을 새 답변/임베딩으로 대체 (덮어쓰기)
- **임베딩 모델 로드 실패**: 시작 시 실패하면 앱 시작 차단, 명확한 오류 메시지 표시
- **.env 파일 부재**: 기본값으로 패스워드 1234 사용, 로그에 .env 미설정 경고 기록
- **사용자 질문 길이 초과**: 500자 제한, 초과 시 "질문은 500자 이내여야 합니다" 메시지 표시
- **관리자 질문 길이 초과**: 500자 제한, 초과 시 "질문은 500자 이내여야 합니다" 메시지 표시
- **관리자 답변 길이 초과**: 2000자 제한, 초과 시 "답변은 2000자 이내여야 합니다" 메시지 표시
- **관리자 로그인 실패 반복**: 로그인 시도 횟수 제한/잠금 없이 재시도 허용
## 요구사항

### 기능 요구사항

- **FR-001**: 시스템은 앱 시작 시 init.txt (줄 단위 JSON)에서 질문/답변을 읽어 ChromaDB에 로드해야 함
- **FR-002**: 시스템은 관리자 로그인 화면을 제공해야 하며, .env 파일의 ADMIN_PASSWORD 환경 변수로 검증해야 함 (기본값: 1234)
- **FR-002A**: 관리자 로그인 상태는 앱 전역 단일 상태로 관리되어야 하며, 한 사용자의 로그인 성공 시 모든 클라이언트에서 관리자 화면 접근이 가능해야 함
- **FR-003**: 관리자는 질문과 답변을 입력하고 "DB 업데이트" 버튼으로 ChromaDB 및 init.txt를 업데이트할 수 있어야 함
- **FR-004**: 사용자는 질문을 입력하고 ChromaDB에서 검색된 유사 답변을 받아야 함
- **FR-005**: 검색 결과가 없으면 정확히 "답변을 찾을 수 없습니다" 메시지를 표시해야 함
- **FR-006**: Langfuse로 모든 ChromaDB 검색 및 관리자 업데이트 작업을 추적해야 함
- **FR-007**: 모든 UI는 Gradio 컴포넌트로 구현해야 함
- **FR-008**: 관리자가 같은 질문을 입력한 경우 기존 항목을 새 답변/임베딩으로 대체해야 함 (덮어쓰기 처리)
- **FR-009**: 사용자 질문 입력은 최대 500자로 제한하며, 초과 시 사용자 친화적 메시지 표시
- **FR-010**: 관리자 질문 입력은 최대 500자, 답변 입력은 최대 2000자로 제한하며, 초과 시 각각 오류 메시지 표시
- **FR-011**: 관리자 화면은 로그아웃 버튼을 제공해야 하며, 클릭 시 전역 로그인 상태를 해제하고 로그인 화면으로 복귀해야 함
- **FR-012**: 관리자 로그인은 실패 횟수 기반 잠금 정책을 적용하지 않으며, 실패 후 즉시 재시도를 허용해야 함
- **FR-013**: 시스템은 임베딩 생성에 ChromaDB 기본 임베딩 함수를 사용해야 함

### 데이터 포맷

**init.txt 파일 형식**: 줄 단위 JSON

각 줄은 하나의 Q&A 항목을 JSON 객체로 표현합니다. 예시:
```
{"question": "Python이란?", "answer": "프로그래밍 언어입니다"}
{"question": "Java란?", "answer": "객체지향 언어입니다"}
```

### 핵심 엔티티

- **QA Item** (질문-답변 쌍): question (str), answer (str), embedding (vector), metadata (dict)
- **Administrator Session**: password, is_authenticated (bool), timestamp, scope (global)

### 벡터 데이터 계약

- **임베딩 모델**: ChromaDB 기본 임베딩 함수 사용
- **유사도 임계값**: 0.7 (기본값, 조정 가능)
- **검색 상위 결과**: 1개 (사용자 질문), 관리자 화면에서는 최대 5개
